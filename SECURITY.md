# Security Policy

## Supported Versions

We will release security updates for supported versions. Currently supported versions are listed in the [CHANGELOG](CHANGELOG.md) or releases page.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately. Do **NOT** create a public issue. Instead, email the project maintainers at [YOUR_EMAIL_OR_CONTACT_INFO] with a detailed description. We will investigate and provide a fix as soon as possible.

Please include the following in your report:

- A description of the vulnerability and its potential impact.
- The steps needed to reproduce the issue.
- Any workarounds you may know of.

All reports are appreciated and will receive a response. We aim to coordinate disclosure with you, and will credit you if desired.

## Security Best Practices

When using this project:

- Do not hard-code API keys or secrets into your code. Use environment variables and `.env` files.
- Regularly update dependencies to incorporate security patches.
- Run automated security scanners (e.g., Dependabot, CodeQL) and review their findings.
- Follow the guidelines in [CONTRIBUTING.md](CONTRIBUTING.md) for secure development.
